# App Escolher Tema (Kotlin)

> Repositório didático: exercício prático de Android nativo com **Kotlin**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Aplicativo em que o usuário escolhe entre **tema claro e tema escuro**, e o app lembra da escolha.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## O que o app faz

- Botões **Claro** e **Escuro** para trocar o tema do app.
- A escolha é salva com `SharedPreferences` e aplicada novamente quando o app é aberto.
- Um texto mostra qual tema está ativo.

## Conceitos trabalhados em aula

- Tema claro/escuro com `AppCompatDelegate.setDefaultNightMode`
- Persistência de preferências com `SharedPreferences`
- Recursos de tema (`values` e `values-night`)

## Tecnologias

- **Kotlin**
- **Android SDK** (Android Studio)
- **Gradle**
- `minSdk 27` / `compileSdk 34`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppEscolherTemaKotlin.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 27 ou superior.
